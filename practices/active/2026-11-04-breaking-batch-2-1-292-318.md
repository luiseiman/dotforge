## Description

1. 2.1.293 — `claude-haiku-5-5` is the default Haiku on the Anthropic API with **1M context** ($0.10/$0.50; $0.50/$2.50 over 100K). `model-ids.md` and `context-window-optimization.md` still list `claude-haiku-4-5-20251001` / 200K / 8K; `model: haiku` in `agents/researcher.md` and `agents/test-runner.md` now resolves to 5.5. **dotforge defect**: `template/hooks/pre-compact-warning.sh` (v4.8.1) assigns a 200K window to any model id containing "haiku" — on 5.5 it under-reports the window 5x. Restrict the 200K branch to `haiku-4`.
2. 2.1.302 — `claude -p` and Agent SDK sessions with no permission mode start in `default` on third-party providers, with telemetry off, or on a fresh install; `--permission-mode auto` keeps auto. `auto-mode.md` claims auto is the default incl. `-p`/SDK on third-party (v2.1.285). Audit item 8 wording to review.

5. System prompt 2.1.318 extraction: "minimize output tokens" and "Use TodoWrite VERY frequently" return 0 matches (as did the two strings removed in v4.9.0). Current style directives: "Lead with the outcome", comments only "to state a constraint the code itself can't show" (2.1.315 dropped "match surrounding comment density"). `prompting-patterns.md` and `rule-effectiveness.md` still list the two stale overrides.
